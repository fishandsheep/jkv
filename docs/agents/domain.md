# Domain Docs

This repository uses a single-context domain documentation layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read ADRs under `docs/adr/` that affect the work.
- Proceed silently when either location does not exist.

## Vocabulary

Use domain terms defined in `CONTEXT.md` consistently in issues, specifications, tests, and implementation. Surface conflicts with existing ADRs explicitly instead of silently overriding them.
